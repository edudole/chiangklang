แก้ไข GitHub หน้า index.html
1) รวม local CSS 17 requests -> 2 bundles (คงลำดับ cascade รอบ inline style เดิม)
   - index-fast-core.css
   - index-fast-profile.css
2) รวม local JavaScript 19 requests -> 1 bundle โดย concat IIFE ตามลำดับเดิม
   - index-fast.js
   - ไฟล์ JS/CSS ต้นฉบับยังอยู่ครบเพื่อให้ subpages และ Admin dynamic loader ใช้ต่อ
3) homefast prefetch ตรวจ browser cache ก่อน
   - ถ้ามี cache อายุไม่เกิน 15 นาที จะไม่ยิง Apps Script ซ้ำตอนเปิดหน้า
4) SiteFast ไม่ background-refresh เมื่อ cache ยังสด
5) request ที่มี cache จะใช้ stale cache เป็น fallback เมื่อ network/Apps Script สะดุดชั่วคราว
6) homefast prefetch มี timeout และ fallback request เพื่อไม่ค้างรอ Promise เดิม
